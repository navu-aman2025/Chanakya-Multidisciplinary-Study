# Chanakya: A Multidisciplinary Study

Welcome to the official website for the multidisciplinary academic study on Chanakya.  
This site presents the complete research project, including sections, diagrams, references, and supporting materials.

## 📘 Overview
This study explores Chanakya’s contributions to:
- Economics  
- Political Science  
- Sociology  
- Governance  
- Statecraft  
- Comparative Philosophy
