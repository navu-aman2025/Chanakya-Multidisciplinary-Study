# Roadmap — Version 1.1  
### Planned Enhancements for the Chanakya Multidisciplinary Study  
**Target Release:** September–October 2026

This roadmap outlines the next set of improvements planned for Version 1.1 of the project. These updates focus on expanding academic depth, improving repository usability, and preparing the study for broader publication formats.

---

### **1.1 Expanded Case Studies**
- Add 2–3 modern governance case studies  
- Include corporate leadership examples inspired by Chanakya  
- Add public administration parallels from Canadian and global contexts  

### **1.2 Additional Comparative Analysis**
- Extend comparisons with Greek, Chinese, and Persian thinkers  
- Add a subsection on modern political theorists  
- Include a comparative table (to be added in List_of_Tables.md)

### **1.3 Strengthened Literature Review**
- Add more peer‑reviewed sources  
- Integrate recent academic papers (2020–2026)  
- Expand commentary on Arthashastra translations

## 🚀 5. Version 1.1 Release Goal
Version 1.1 aims to:

- Expand academic depth
